# エコーラン デザイン刷新 設計書

ゲーム「エコーラン」の見た目（色・質感・光と影・絵の描き方）を作り直すための設計書です。デザイナーやデザイン生成 AI にそのまま渡せるように書いています。

- **変えるもの**：色、質感（テクスチャ）、影や光の表現、線や角の形、ゲーム内の絵の描き方、アイコンの絵柄
- **変えないもの**：画面の配置、部品の大きさ、文字の大きさ、画面の流れ（今のスクリーンショットどおり）
- 参考画像：`docs/design/current/`（今の画面）、`docs/design/concepts.jpg`（方向性3案）

---

## 1. ゲームの概要

**エコーラン**は、スマホ向けの1画面アクションゲーム（Android アプリと Web 版）。

- コインを取るたびに時間が巻き戻り、さっきまでの自分が **「残像」** になって同じ道を往復しつづける。残像に触れたらゲームオーバー。
- **敵はぜんぶ、過去の自分**。ループを重ねるほど残像が増えていく。
- DASH で一瞬だけ残像をすり抜けられる。アイテム（消しゴム・砂時計）、スキル、スキン（34種）、実績、デイリーチャレンジがある。
- 遊ぶ人：すき間時間に遊ぶ10代〜30代。縦持ちのスマホが中心（横持ち・タブレット・PC にも対応）。

**世界観の芯**：「時間」「残響（エコー）」「重なる過去」。見た目でこれを表現できると強い。

## 2. 今のデザインの課題（なぜ「AI っぽい」か）

`docs/design/current/` を参照。配置や大きさは良いが、色と質感に固有の世界観がない。

1. **濃紺のグラデーション背景＋方眼の重ね**：よく見る「夜のテック UI」。どのゲームにも当てはまる。
2. **アクセント色が多すぎる**：アンバー・コーラル・水色・ミント・紫が同列に並び、主役の色がない。
3. **つやのあるハイライトとぼかし影**：ボタンの放射グラデーション、全部品のぼかしたドロップシャドウ、光彩。根拠のない「立体感」が汎用テンプレート感を出している。
4. **半透明の白で全部を描いている**：線・カード・残像が同じ「白 10〜20% 透明」で、素材感がない。
5. **質感が意味を持っていない**：粒子ノイズや方眼が飾りとして乗っているだけで、ゲームの仕組み（残像・巻き戻し）とつながっていない。

## 3. 守ってほしいこと（すべての案に共通）

**配置・大きさ**
- 画面の配置・部品の大きさ・文字サイズは今と同じ（スクリーンショットを下敷きにする）。基準の画面サイズは 390×844（スマホ縦）。
- タップできる部品は 44×44px 以上。

**読みやすさ・アクセシビリティ**
- 文字と背景のコントラストは 4.5:1 以上（大きい文字・太い数字は 3:1 以上）。**白文字を明るい色の上に置かない**（例：ピンクの上の白文字は不可）。
- ゲーム中、自機・残像・コイン・アイテムは半径 19px 前後の小ささでも一瞬で見分けられること。**色だけで区別しない**（残像は輪郭や透け方、自機は塗りと目、など形でも区別する）。
- 危険（残像が近い・時間切れ間近）は赤系＋形や動きでも伝える（色覚の多様性への配慮）。

**ゲームとしての制約**
- 盤面は 1000×1000 の正方形を縮小して描く Canvas。毎フレーム重い処理（ぼかし・大きなフィルター）はできない。質感は **小さな繰り返し画像（256px 以下）や、一度だけ描いて使い回す画像** で表現する。
- テーマは1つ（明るい or 暗い）。Android のステータスバー・スプラッシュの色も合わせる。
- スキン（キャラクターの色違い）は34種ある。新しい背景の上でもすべて見分けられること（明るい背景なら輪郭線を足す、など色の調整方針を示す）。

**フォント**
- 今：見出し・ロゴ「Dela Gothic One」、本文「M PLUS Rounded 1c」（500/800）、数字・ラベル「IBM Plex Mono」（500/600）。
- 変えてもよいが、無料で商用利用できて（OFL など）日本語が揃うものに限る。

**やらないこと（AI っぽさの元）**
- 目的のないグラデーション、ネオンの光彩、すりガラス（背景ぼかし）、つやつやのハイライト
- 全部品へのぼかし影
- 意味のない装飾テクスチャ
- 絵文字のようなアイコン、線の太さがばらばらなアイコン

## 7. 方向性（3案）

`docs/design/concepts.jpg` が3案のラフ。どれか1つを選んで、全画面に広げる。

### A. リソグラフ（おすすめ）

**ひとことで**：紙に刷った版画。残像は「ずれて重なった版」。

- **なぜ合うか**：リソグラフは色ごとに版を重ねて刷るので、版が少しずれる。その「ずれて重なった像」が、このゲームの「過去の自分が重なる」仕組みそのもの。明るい紙の色は、暗い画面ばかりのストアで目立つ。
- **キーワード**：手刷り、インディー、ポップ、紙、版ずれ、網点、スタンプ
- **テーマ**：明るい

| 役割 | 色 |
| --- | --- |
| 紙（背景） | `#F3ECDD` |
| 面 | `#FFF8EA`（少し明るい紙） |
| くぼみ | `#E8DFCC` |
| 墨（線・文字） | `#23252E` |
| 文字（弱） | `#6B6656` |
| 蛍光ピンク（主役・自機） | `#FF4F9A`（上に乗せる文字は墨色） |
| 青（残像・スキル・情報） | `#2F5BB7` |
| 黄（コイン・カケラ・強調） | `#FFD400` |
| 赤（危険・DASH） | `#F15A4A` |
| 緑（成功） | `#00A36C` |
| レア度 | N 灰インク `#A8A291` ／ R 青 ／ SR ピンク ／ UR 黄＋ピンク＋青の重ね刷り |
| ★1〜5 | 灰・緑・青・ピンク・黄 |

- **質感**：紙の繊維ノイズ（掛け合わせ 25〜35%）。陰影は **網点（ハーフトーン）** で付ける（グラデーションは使わない）。
- **光と影**：ぼかし影は使わない。**別の色の版を 3〜5px ずらした「版ずれ影」**、または墨色の硬い影で立体を出す。
- **形**：墨色の線 2〜2.5px、角丸 10〜12px。スタンプやシールのような部品。
- **盤面**：紙＋薄い網点。四隅に印刷の **トンボ（裁ち落としの目印）**。方眼はやめる。
- **自機・残像**：自機はスキン色の塗り＋墨の輪郭。残像は青インクで、掛け合わせて重なると色が濃くなる。古い残像ほど版ずれが大きく、色が薄い。すり抜け中は網点だけで描く。
- **演出**：巻き戻しは版がずれて戻るように。フリーズは青の網点の膜、STORM は版ずれが震える。パーティクルは紙吹雪のようなインクの欠片。
- **注意**：蛍光ピンクの上に白文字は読めない（墨色の文字にする）。色数は5インクまで。

### B. 和紙と墨

**ひとことで**：和紙に墨・朱・藍だけで描く。残像は「にじんだ藍墨」。

- **なぜ合うか**：墨のにじみや薄墨は「時間が経って薄れる記憶」を表せる。日本らしい上品さで、他のゲームと被らない。
- **キーワード**：和紙、墨、朱印、藍染め、余白、罫線
- **テーマ**：明るい

| 役割 | 色 |
| --- | --- |
| 和紙（背景） | `#ECE5D6` |
| 面 | `#F4EFE4` |
| くぼみ | `#E1D8C5` |
| 墨（線・文字・主役ボタン） | `#1B1A18` |
| 薄墨（文字（弱）・線） | `#8A8272` |
| 朱（自機・危険・DASH・判子） | `#D9452B` |
| 藍（残像・スキル） | `#2B4A7E` |
| 金茶（コイン・カケラ） | `#C49A2C` |
| 青磁（成功） | `#5E8C6A` |
| レア度 | N 薄墨 ／ R 藍 ／ SR 古代紫 `#6B4C8A` ／ UR 金茶 |
| ★1〜5 | 薄墨・青磁・藍・古代紫・金茶 |

- **質感**：和紙の繊維（一方向に流れるノイズ）。残像や筆の線は **にじみ**（輪郭が少しゆらぐ）。
- **光と影**：影はほぼ使わない。面の重なりは「紙を一枚重ねる」「罫線で区切る」で表す。
- **形**：細い罫線（1.5px）、角はほぼ四角（2〜4px）。主役ボタンは墨の帯＋朱の判子。
- **盤面**：和紙＋原稿用紙や碁盤のような薄墨の格子。
- **自機・残像**：自機は朱の塗り。残像は藍墨のにじみで、古いものほど薄墨に近づく。コインは金茶の穴あき銭のような形。
- **演出**：巻き戻しは墨が逆に吸い込まれる。フリーズは藍のにじみが止まる。ゲームオーバーは朱が飛び散る。
- **注意**：地味になりやすい。朱は1画面に1〜2か所だけ。ループ数を漢数字（七周目）にするなら読みやすさを確認。

### C. 暗室フィルム

**ひとことで**：写真の暗室とフィルム。黒は青ではなく温かい黒。

- **なぜ合うか**：フィルムの「コマ」と「巻き戻し」が、ループと巻き戻しの仕組みに重なる。今の暗い雰囲気は残しつつ、汎用的な紺色から抜け出せる。
- **キーワード**：暗室、セーフライト、フィルムの粒子、ネガ、コマ番号、パーフォレーション
- **テーマ**：暗い

| 線 | `#3A322A` |
| 文字（クリーム） | `#EFE6D2` |
| 文字（弱） | `#9C8F7B` |
| セーフライトの赤（自機・危険・DASH） | `#FF5A36` |
| ネガのシアン（残像・スキル） | `#7FD6CF` |
| フィルムのアンバー（コイン・カケラ） | `#E8B04B` |
| 主役ボタン | クリームの塗り＋黒文字 |
| 成功 | `#9BC53D` |

- **質感**：フィルムの粒子（固定の細かいノイズ、スクリーン合成 15〜22%）、画面の端がほんのり暗いビネット。
- **光と影**：ぼかし影は使わない。光るのは自機（セーフライト）だけ。
- **形**：角丸は小さめ（4〜8px）。ラベルは等幅フォントの大文字、字間広め（編集デザイン風）。
- **盤面**：フィルムの1コマ。左右にパーフォレーション（送り穴）、端にコマ番号（例：FRAME 07）。
- **自機・残像**：自機は赤い塗り＋淡い光。残像はシアンの輪郭（ネガの反転色）、古いものほど粒子が粗く薄い。
- **演出**：巻き戻しはフィルムの逆送り（コマが流れる）。フリーズは画面が止まったコマのように少し揺れる。ゲームオーバーは露光オーバーで白く飛ぶ。
- **注意**：暗い画面はストアで埋もれやすい。赤とアンバーが近い色にならないよう注意。

## 8. 作ってほしいもの（デザイナー・デザイン AI への依頼内容）

選んだ1案について：

1. **色と質感の一覧表**：6章の役割ごとの色（HEX）、線の太さ、角丸、影の付け方、テクスチャ（繰り返し画像）
2. **画面のモック（390×844）**：起動、ホーム、スキン、スキル、ミッション（デイリー／実績）、記録、設定、一時停止、結果、シェア、あそびかた、ログインボーナス、フィードバック、チュートリアル
3. **プレイ中の画面**：通常／ニアミスの瞬間／フリーズ中／ECHO STORM／巻き戻し中／ゲームオーバー
4. **部品の状態**：ボタン（主役・通常・危険・押した・使えない）、カード、トグル、スライダー、セグメント、バッジ、トースト、タブ（選択・非選択・バッジ付き）、スキンの枠（所持・未所持・装備中・選択中）、スキルのカード（装備中・未装備・ロック）
5. **盤面の部品を1つずつ**：自機、残像（新しい・古い・すり抜け中・危険）、予知ドット、コイン、消しゴム、砂時計、時間バー、CHAIN の札、パーティクル、得点のポップアップ
6. **アイコン**：タブ5種と設定などの 24px アイコン（線の太さを揃える）
7. **アプリアイコン**（Android のアダプティブアイコン：前景と背景を分けて、中央66%に収める）、**フィーチャーグラフィック**（1024×500）、**シェア用の画像カード**（1080×1350）
8. 横持ち1画面、タブレット1画面

## 10. 実装するときのメモ（開発者向け）

デザインが決まったら、次の場所を差し替える。

- **色の変数**：`index.html` 冒頭の `:root`（`--bg-0` 〜 `--mint` など）。CSS はほぼこの変数を参照している。
- **ボタンや部品の影**：CSS の `box-shadow`（約60か所）とボタンの `radial-gradient`。
- **盤面の描画**：`drawArena`（背景・方眼・粒子ノイズ `grain`）、残像・自機・コイン・アイテム・時間バー・演出の描画。Canvas は CSS 変数の一部（`C` オブジェクト）を読み、それ以外は色を直接書いているので、ここもトークン化する。
- **スキン**：`SKINS`（34種の色・模様）。新しい背景で見分けにくいものは色を調整する。
- **そのほか**：シェア用の画像カード（`makeShareCard`）、アイコン（`I`）、PWA の `manifest.webmanifest` の `theme_color`／`background_color`、Android の `assets/`（アイコン・スプラッシュの元画像）と `android/app/src/main/res/values/colors.xml`、ストア用画像（`store/`）。
- 質感の画像は 256px 以下の繰り返しにして、Canvas では一度だけパターンを作って使い回す（毎フレームのフィルター処理は避ける）。
