## ストアの掲載情報

**アプリ名**（30文字まで）

```
エコーラン - タイムループアクション
```

**簡単な説明**（80文字まで）

```
コインを取るたび時間が巻き戻る。敵はぜんぶ過去の自分。1画面のタイムループ・アクション！
```

**詳しい説明**（4,000文字まで）

```
コインを取るたび、時間が巻き戻る。
さっきまでの自分は「残像」になって、同じ道を往復しつづける。
触れたらアウト。敵はぜんぶ、過去のあなた。

■ あそびかた
・画面のどこでもドラッグして移動。コインを取るとループクリア
・前のループの自分が残像になって追いかけてくる
・DASH で一瞬だけ残像をすり抜けられる
・寄り道すると残像の通り道が長くなり、あとのループで自分の首を絞める
・3秒以内にコインを取り続けると CHAIN でスコアアップ

■ やりこみ要素
・レベルを上げるとスキルが解放（タイムストップ、ブリンク、シールドなど12種類）
・34種類のスキン（ネコ耳、王冠、銀河… 実績やレベルの限定スキンも）
・★1〜★5の実績54種、毎日のミッション、ログインボーナス
・全員が同じ配置で遊べるデイリーチャレンジ。結果は画像でシェアできる

■ こんな人におすすめ
・すき間時間にサクッと遊べるゲームを探している
・何度でもリトライしたくなるアクションが好き
・ハイスコアを友だちと競いたい

■ そのほか
・広告なし、アカウント登録なし
・オフラインでも遊べます
・縦画面・横画面、スマホ・タブレットに対応
・ゲーム内の「フィードバックを送る」から、不具合や要望を開発者に直接送れます
```

**アプリのカテゴリ**: ゲーム › アクション（またはアーケード）
**タグ**: アクション、カジュアル、シングルプレイヤー、オフライン
**プライバシー ポリシー**: `https://aasergk-rgb.github.io/game/privacy.html`（GitHub Pages を公開してから）
**連絡先メールアドレス**: ストアに公開される。デベロッパー用のアドレスを用意するのがおすすめ。

## アプリのコンテンツ（Play Console の申告）

**アプリのアクセス権**: すべての機能を制限なしで利用できる（ログインなし）

**広告**: 広告は含まれていない
**広告 ID**: 使用しない

**コンテンツのレーティング**（アンケート）: カテゴリ「ゲーム」。暴力・性的表現・ギャンブル・薬物・暴言なし。ユーザー同士のやりとりなし（シェアは端末の共有機能で外部アプリに渡すだけ）。デジタル購入なし。位置情報なし。→ 全年齢向けの判定になる見込み。

**ターゲット層**: 内容は全年齢向け。13歳未満を対象に含めると「ファミリー ポリシー」の追加要件と審査がかかる（広告やデータ収集が少ないので対応は可能）。迷う場合は「13歳以上」を選ぶと手続きが簡単。実際の想定プレイヤーに合わせて選ぶこと。

**ニュースアプリ / 健康 / 金融 / 政府 / COVID-19**: いずれも該当しない

### データ セーフティ

フィードバック機能があるので「データを収集する」と答えます。

- ユーザーデータを収集または共有しますか → **はい**
- 転送時に暗号化されますか → **はい**（HTTPS）
- データの削除をリクエストできますか → **はい**（アプリ内のフィードバック、または連絡先メールで依頼。プライバシーポリシーに記載）
- 共有（第三者への提供）→ **なし**（Google Apps Script・Google スプレッドシート・Gemini API は開発者の代わりに処理するサービス提供者なので「共有」には当たらない）

| データの種類 | 収集 | 必須／任意 | 目的 |
| --- | --- | --- | --- |
| 個人情報 › メールアドレス | する | 任意（返信がほしいときだけ） | アプリの機能（問い合わせへの返信） |
| アプリのアクティビティ › その他のユーザー作成コンテンツ（フィードバックの本文） | する | 任意（送ったときだけ） | アプリの機能、分析（改善のため） |
| アプリの情報とパフォーマンス › 診断（端末情報） | する | 任意（「端末情報を送る」がオンのとき） | アプリの機能（不具合の調査） |
| デバイスまたはその他の ID（ランダムな識別子） | する | フィードバックを送るときは必須 | 不正行為の防止、セキュリティ |

ゲームの記録や設定は端末の中にだけ保存し送信しないので、申告の対象外です。
