エコーラン プライバシーポリシー

最終更新日：2026年10月21日

1. はじめに

このポリシーは、ゲーム「エコーラン」（Android アプリ版・Web 版。以下「本アプリ」）が扱う情報について説明します。本アプリは個人の開発者が提供しています。

本アプリには 広告・アクセス解析・トラッキングはありません。アカウント登録もありません。

2. 端末の中だけに保存する情報

次の情報は、遊んでいる端末（ブラウザやアプリの保存領域）にだけ保存し、外部には送りません。

  • スコア・記録・実績・レベル・カケラ・スキン・スキルなどのゲームの進み具合
  • サウンドや操作などの設定
  • ランダムに作られる識別子（フィードバックを送るときだけ使います。下の3を参照）

設定の「記録と実績を消す」で消去できます。アプリをアンインストールしたり、ブラウザのサイトデータを消したりしても消えます。Android の端末のバックアップ機能を使っている場合、この保存データがバックアップに含まれることがあります。

3. フィードバックを送ったときに送信する情報

設定の「フィードバックを送る」から送信したときだけ、次の情報を開発者に送ります。

  • フィードバックの種類と本文
  • 返信用のメールアドレス（入力した場合のみ）
  • 端末情報（「端末情報もいっしょに送る」がオンの場合のみ）：ブラウザ／OS の情報、画面サイズ、言語設定、ゲームのレベル・最高ループ数・プレイ回数
  • アプリの種類（Android アプリ／Web 版）とバージョン
  • ランダムな識別子（同じ端末からの大量送信を防ぐためだけに使います。個人を特定するものではありません）

使いみち：不具合の修正、ゲームの改善、返信を希望された場合の連絡のためだけに使います。

送信先と保存：通信は暗号化（HTTPS）されます。届いた内容は開発者の Google アカウント上（Google Apps Script・Google スプレッドシート）に保存され、開発者へのメール通知に使われます。

AI による仕分け：どのくらい急いで対応すべきかを判定するため、フィードバックの種類と本文、アプリの種類とバージョンを Google の Gemini API に送ります。返信用メールアドレスと端末情報は送りません。Gemini API に送った内容は Google の規約に従って取り扱われ、利用条件によっては Google がサービスの改善に使うことがあります。本文には名前や住所などの個人情報を書かないでください。

保存期間：改善や対応に必要な期間（最長2年）保存し、その後削除します。

削除の依頼：送った内容を消してほしいときは、フィードバックでその旨と、送った日時・内容の一部（返信用メールアドレスを書いた場合はそのアドレス）をお知らせください。確認のうえ削除します。

4. シェア機能

結果のシェアでは、あなたが選んだサービス（X・LINE・端末の共有メニューなど）に、あなたが選んだ内容（スコアなどの文章や画像）を渡すだけです。本アプリが開発者に送ることはありません。送り先での扱いは、それぞれのサービスのポリシーに従います。

5. Web 版について

Web 版は GitHub Pages で配信しています。配信のため、GitHub がアクセスの記録（IP アドレスなど）を扱うことがあります。詳しくは GitHub のプライバシーに関する声明 をご覧ください。フォントなどはすべてサイト内のファイルを使い、外部のサービスからは読み込みません。

6. お子さまの利用

本アプリは年齢を問わず遊べます。お子さまが情報を集められることはありませんが、フィードバックを送るときは保護者の方と一緒に送るようにしてください。

7. このポリシーの変更

内容を変えるときは、このページを更新し、上の最終更新日を変えてお知らせします。

8. お問い合わせ

本アプリの設定にある「フィードバックを送る」、または Google Play のストアページに記載のデベロッパーの連絡先からお問い合わせください。
