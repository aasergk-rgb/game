# エコーラン（ECHO RUN）

**コインを取るたび時間が巻き戻る。敵はぜんぶ、過去のあなた。**

前のループで走った自分が「残像」になり、同じ道を往復しつづける。過去の自分をかわしながらループを重ねる、1画面のタイムループ・アクションです。

`index.html` 1ファイルで動きます（Web 版はビルド不要）。スマホにインストールできる PWA と、Android アプリ版もあります。

## モード

| モード | 内容 |
| --- | --- |
| エンドレス | 毎回ちがう配置でどこまでループを重ねられるか挑戦する |
| デイリー | 日付ごとにコインとアイテムの位置が固定。だれが遊んでも同じ配置なので、結果をコピーして友だちと比べられる |

## ルール

- コインを取るとループクリア。時間が巻き戻り、次のループが始まる。制限時間は8秒。
- 前のループの自分は **残像** になり、同じルートを往復しつづける。触れたらアウト。
- ループ開始直後の約1秒は残像に当たらない（点線表示）。

## ゲームの仕組み

| 仕組み | 効果 |
| --- | --- |
| 寄り道 | 寄り道したぶん残像の通り道が長くなり、後のループで自分の首を絞める |
| ダッシュ | 一瞬だけ加速し、残像をすり抜けられる（+15）。使ったあと約1.4秒は使えない |
| ニアミス | 残像に触れずにすぐ横をかすめると +25、一瞬スローモーション |
| CHAIN | 3秒以内のクリアが続くと、コインの得点倍率が最大×3まで上がる |
| 赤い消しゴム | 4ループごとに出現。いちばん長い残像を1体消せる（+50） |
| 砂時計 | 6ループごとに出現。残像の動きが2.5秒止まる（+30） |
| ECHO STORM | 10ループ目から5ループごと。残像が1.5倍速で動く |
| 予知ドット | 各残像の少し先の動きを点で表示（設定で切り替え可） |

コインの得点は「(100 + 残り秒数×10) × CHAIN倍率」です。

## やりこみ要素

- **カケラ（ゲーム内通貨）**：プレイ（2ループ = 1、スコア1,000点 = 1、その日最初のデイリー +5）、実績、デイリーミッション、ログインボーナス、レベルアップでもらえる。スキンショップで使う。
- **スキン 34種**（目安：はじめて遊んだ日に N スキン1体、R は数日、UR は数週間）：色・模様（ストライプ、ドット、グラデーション、虹色、銀河など）・アクセサリー（ネコ耳、王冠、天使の輪、帽子など）・目の形の組み合わせ。レア度は N / R / SR / UR。
  - ショップで買えるもの（◆150〜1,800）
  - 実績の報酬でしかもらえない限定スキン
  - レベル報酬（Lv.5 / 10 / 15 / 20 / 30）
  - ログインボーナス7日目の限定スキン
- **実績 54種**：★1（かんたん）〜★5（伝説）の5段階。達成したら「受け取る」でカケラ（★1 = 5、★2 = 15、★3 = 30、★4 = 60、★5 = 120）や限定スキンがもらえる。実績をタップすると詳細画面（条件・記録の種類・進み具合・達成日・報酬・コツ・同じシリーズの実績）が開き、そこから受け取りや挑戦ができる。スキン画面の「入手方法を見る」からも、その実績・レベル報酬・ログインボーナスへ直接移動できる。進み具合はバーで表示。
- **レベル**：プレイでXPがたまる（1ループ = 10、スコア100点 = 1、ミッション受け取り = 10）。レベルが高いほど次までに必要なXPが増える。上がるたびにカケラ、決まったレベルで **新しいスキル** や限定スキン。プロフィールをタップすると報酬の一覧が見られる。
- **デイリーミッション**：毎日3つ（日付ごとに全員共通、1つ ◆10〜25）。3つともクリアするとコンプリートボーナス ◆20。
- **ログインボーナス**：7日周期（◆10〜40、7日目は限定スキン）。連続ログイン日数は実績にもなる。
- **称号**：到達ループ数で「迷子」から「エコーマスター」まで。
- **記録**：モード別 TOP 5 と通算成績。
- **画像シェア**：結果を1080×1350の画像カード（ロゴ・走ったルート・スコア・称号・記録・スキン）にして、保存・端末の共有メニューで送信・コピーができる。
- **シェア**：結果画面と記録タブの「シェア」から、X・LINE・Facebook・Threads・Bluesky への投稿、コピー、端末の共有メニュー（対応端末のみ）を選べる。シェアの実績（はじめてのシェア・記念撮影・デイリー自慢・宣伝部長＝限定スキン「アイドル」）もある。
- **軌跡**：走った全ルートを1枚の絵として表示。

## スキル

レベルが上がると使えるスキルが増えていきます。下のタブの「スキル」で装備を選びます（新しいスキルは、空いている枠があれば自動で装備される）。チュートリアルではスキルは使えません。

- **パッシブスキル**：装備しているあいだ効果が続く。装備枠は Lv.2 で1つ、Lv.7 で2つ、Lv.14 で3つ。
- **アクティブスキル**：1つだけ装備できる。コインを取るたびにチャージがたまり、満タンになったら **SKILL ボタン**（DASH の上。キーボードは E、ゲームパッドは Y / LB）で発動。使うとチャージは0に戻る。

| Lv. | スキル | 種類 | 効果 |
| --- | --- | --- | --- |
| 2 | ロングダッシュ | パッシブ | ダッシュで進む距離が1.4倍 |
| 3 | マグネット | パッシブ | コインやアイテムを取れる範囲が広がる |
| 4 | タイムストップ | アクティブ（コイン3枚） | 残像を2秒間止める |
| 6 | セーフスタート | パッシブ | ループ開始直後の無敵時間が0.9秒→1.8秒 |
| 8 | クイックチャージ | パッシブ | ダッシュの回復が1.4秒→1.0秒 |
| 9 | ブリンク | アクティブ（コイン2枚） | 向いている方向へ瞬間移動（着地のあと一瞬だけ無敵） |
| 11 | ニアミス名人 | パッシブ | ニアミスの判定が広がり、得点が+25→+50 |
| 13 | タイムプラス | パッシブ | 制限時間が8秒→10秒 |
| 15 | シールド | アクティブ（コイン4枚） | 3秒間、残像に当たっても平気 |
| 17 | チェインキープ | パッシブ | CHAINが続く時間が3秒→4.5秒 |
| 19 | イレイズ | アクティブ（コイン5枚） | いちばん近い残像を1体消す |
| 22 | ラストチャンス | パッシブ | 1回のプレイで1度だけ、残像に当たっても耐える |

スキルの実績（はじめてのスキル・九死に一生・スキルコンプリート）もあります。

記録・実績・カケラ・設定はブラウザの localStorage に保存されます（サーバーには送りません）。

## 画面と操作

スマホ・タブレットを主役にしたアプリ風の UI です。

- **起動画面 → ホーム**：ホームには自分のキャラクター、デイリーチャレンジ、プレイボタン。下のタブで「ホーム / スキン / 実績 / 記録」を切り替え。
- **スキン画面**：上のプレビュー（キャラクター・レア度・入手方法・購入／装備ボタン）は固定で、下のスキン一覧だけがスクロールする。横持ちではプレビューが左、一覧が右。
- **レベルとXP**：プレイするたびに経験値がたまり、レベルが上がる。実績は進み具合がバーで見える。
- **ゲーム画面**：画面のどこでも指を置くとスティックが出る（指を置いた場所が中心）。右下の DASH でダッシュ、2本目の指でタップしてもダッシュ。縦持ちは盤面の下、横持ちは左右が指のスペース。
- **チュートリアル**：はじめてのプレイは、実際の盤面で操作しながら覚える4ステップのチュートリアルから始まる（移動 → コイン → 残像をよける → ダッシュで壁をすり抜ける）。ぶつかってもゲームオーバーにならず、そのステップをやり直すだけ。右上の「スキップ」でいつでも飛ばせて、設定やあそびかたからもう一度遊べる。
- **ポーズ・設定・リザルト・あそびかた** は下から出るシート（タブレット・PC では中央のカード）。閉じるときも下へスライドして消え、上端のグレーのバーあたり（またはいちばん上までスクロールした状態の中身）を下へスワイプしても閉じられる。あそびかたはスワイプで読むカード形式。
- **再開カウントダウン**：一時停止から戻ると「3・2・1」のあとに再開する（その間にスティックへ指を置いておける）。
- **初登場のヒント**：消しゴム・砂時計・ECHO STORM がはじめて出たときだけ、盤面に短い説明が出る。
- **リザルト**：スコアのカウントアップ、称号、XP、シェア（スマホは共有シート、PC はクリップボード）、走った軌跡の表示。

| | キーボード | マウス（設定で「マウス」） | タッチ | ゲームパッド |
| --- | --- | --- | --- | --- |
| 移動 | WASD / 矢印キー | カーソルの方向へ進む | どこでもドラッグ | 左スティック / 十字キー |
| ダッシュ | Space / Shift / J | クリック | DASH ボタン、2本目の指 | A / B / X / RB |
| スキル | E / L / C | E | SKILL ボタン | Y / LB / LT |
| 一時停止 | P / Esc | 左上のボタン | 左上のボタン | START |
| リトライ | プレイ中に R 長押し、結果画面で Space / R | | リトライボタン | SELECT 長押し |
| メニュー | ↑↓ で選んで Enter、Esc でもどる | | | 十字キーで選んで A、B でもどる |

操作を助ける仕組み：ダッシュの先行入力、自機まわりのダッシュ回復ゲージと向きの矢印、近くの残像の赤い強調、盤面上端のタイムバー（CHAIN になる3秒の目印つき）。

## アプリとして遊ぶ

### Web 版（PWA）

GitHub Pages で公開した Web 版は PWA（インストールできる Web アプリ）です。

- **インストール**：Android の Chrome などでは、ブラウザのインストール表示か、ゲームの **設定 › アプリ › アプリとしてインストール** から追加できる。iPhone / iPad は Safari の共有ボタン →「ホーム画面に追加」。アイコンから起動すると、アドレスバーのない全画面で遊べる。
- **オフライン**：一度開けば、ゲーム本体・フォント・アイコンが端末に保存され（`sw.js`）、電波がなくても起動して遊べる。
- **更新**：オンラインのときは起動時に最新版を取りに行く（3秒以上かかるときは保存済みの版で起動する）。公開のたびに保存済みのデータも入れ替わる。
- フォントはサイトに同梱している（`fonts/`）。Google Fonts には接続しない。

関係するファイル：`manifest.webmanifest`（名前・アイコン・インストール画面のスクリーンショット）、`sw.js`、`icon-*.png`、`icon-maskable-*.png`、`apple-touch-icon.png`、`screenshots/`。

### Android アプリ

Web 版と同じ `index.html` を [Capacitor](https://capacitorjs.com/) で包んだ Android アプリです（`android/`）。ゲームはすべて端末の中にあり、通信なしで動きます。

アプリ版だけの動き：

- **戻るボタン**：シートを閉じる → タブをホームに戻す → ホームでアプリを閉じる。プレイ中は一時停止。
- **バックグラウンド**：ホームに戻ったり電話が来たりすると自動で一時停止し、音も止まる。
- **画像シェア**：「画像を保存」はスマホの `Documents/EchoRun` フォルダに保存。「画像をシェア」「その他」は Android の共有メニュー、「コピー」はクリップボードを使う。
- **振動**：Android の振動機能を使う（設定でオフにできる）。
- 画面の向きは縦・横どちらにも対応。ステータスバーやジェスチャーバーにはかぶらない。

#### APK を手に入れる（GitHub Actions）

`index.html` や `android/` を変更して push すると、`.github/workflows/android.yml` が自動でアプリをビルドします。

1. GitHub の **Actions › Android app** で、いちばん上の実行を開く。
2. 下の **Artifacts** から `echorun-android-…` をダウンロードして展開する。
3. `echorun-…-debug.apk` をスマホに送ってタップ（「提供元不明のアプリ」のインストールを許可する）。

テスト版（debug）は「エコーラン β」という名前で、アプリ ID は `io.github.aasergkrgb.echorun.debug` です。Google Play 版とは別のアプリとして並べて入れられます。テスト版はどのビルドも同じ鍵（`android/app/debug.keystore`、テスト専用）で署名しているので、新しい APK を上から入れればそのまま更新されます（記録も引き継がれる）。

#### 手元でビルドする

Node.js 22 以上、JDK 21、Android SDK（Android Studio）が必要です。

```sh
npm ci
npm run android:debug     # android/app/build/outputs/apk/debug/app-debug.apk ができる
npm run android:open      # Android Studio で開く（エミュレーターや実機で実行）
```

`index.html` を変えたら `npm run sync` でアプリ側にコピーします（`www/` は自動で作られる中間フォルダ）。

#### Google Play で公開する

1. アップロード用の署名鍵を作る（Play Console の「Play アプリ署名」を使えば、なくしても Google に申請して作り直せる。それでもバックアップしておく）：
   ```sh
   keytool -genkeypair -v -keystore echorun-release.jks -alias echorun -keyalg RSA -keysize 2048 -validity 10000
   ```
2. リポジトリの **Settings › Secrets and variables › Actions** に4つ登録する：

   | 名前 | 中身 |
   | --- | --- |
   | `ANDROID_KEYSTORE_BASE64` | `base64 -w0 echorun-release.jks` の出力 |
   | `ANDROID_KEYSTORE_PASSWORD` | 鍵ストアのパスワード |
   | `ANDROID_KEY_ALIAS` | `echorun` |
   | `ANDROID_KEY_PASSWORD` | 鍵のパスワード |

3. 次のビルドから、署名済みの `echorun-….aab`（Google Play 用）と `echorun-….apk` も Artifacts に入る。`v1.0.0` のようなタグを push すると、GitHub の Releases にも APK が添付される。
4. [Google Play Console](https://play.google.com/console) でアプリを作り、`.aab` をアップロードする。バージョン番号（versionCode）は Actions の実行番号で自動的に増える。
5. ストアの説明文・画像・データ セーフティなどの申告内容は [`store/README.md`](store/README.md) にまとめてある（フィーチャー グラフィック、1080×1920 のスクリーンショット、タブレット用の画像も `store/` にある）。

アプリ ID は `io.github.aasergkrgb.echorun`（`capacitor.config.json` と `android/app/build.gradle`）。Google Play に一度公開すると変えられないので、変えるなら最初の公開の前に。

## 設定

サウンド（全体のオンオフ、BGM、効果音）、スティック感度、左利きレイアウト、振動、PCの移動方式、予知ドット、画面の揺れ、フラッシュ演出、当たり判定の表示、全画面表示を変更できます。OS でアニメーションを減らす設定にしていると、揺れとフラッシュは最初からオフになります。設定のいちばん下に、アプリのバージョンとプライバシーポリシー（`privacy.html`）へのリンクがあります。

## フィードバック

設定の **フィードバックを送る** から、種類（不具合・要望・感想・その他）と本文、返信用のメールアドレス（任意）、端末情報（オンオフできる）を開発者に送れます。

- 届いたフィードバックは、開発者の Google Apps Script（[`feedback-server/`](feedback-server/README.md)）が Gemini で重要度を判定し、スプレッドシートに記録してメールで知らせる。**緊急はすぐ、重要（高）は毎朝のまとめ、改善の参考（中）と感想（低）は毎週月曜のまとめ**。
- Gemini の API キーはサーバー側（スクリプト プロパティ）にだけ置き、アプリやリポジトリには入れない。
- オフラインで送ったものは端末に保存し、次に起動したときやネットにつながったときに自動で送る。連続送信は20秒あける。
- 送り先は `index.html` の `const FEEDBACK_URL` に設定済み（Apps Script のウェブアプリの URL）。サーバーを作り直して URL が変わったときはここを書き換える（空にするとフィードバックの項目は表示されない）。

## 公開（GitHub Pages）

`.github/workflows/pages.yml` で、`main` ブランチへの push 時に Web 版のファイル（Android 用のファイルは除く）を GitHub Pages へ自動デプロイします。

1. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする。
2. このブランチを `main` にマージする（または Actions タブから手動実行）。
3. `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される。プライバシーポリシーは `…/privacy.html`（Google Play の申告に使う）。

## 技術メモ

- 素の HTML / CSS / JavaScript。Canvas 2D 描画、60 ステップ/秒の固定タイムステップ。Web 版もアプリ版も同じ `index.html` で動く（アプリでは `window.Capacitor` があるときだけネイティブ機能を使う）。
- フォントはゲーム内で使う文字だけに絞って同梱（約210KB）。ゲームに新しい文字を足したら `python3 scripts/subset-fonts.py` で作り直す（要 `pip install fonttools brotli`）。
- BGM と効果音は Web Audio API でその場で合成（音声ファイルなし）。BGM はループ数に応じてテンポと楽器が増える。
- デイリーの配置は日付とループ番号から作るシード付き乱数で決まるため、プレイヤーの動きに関係なく同じ配置になる。
