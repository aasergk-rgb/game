# エコーラン（ECHO RUN）

**コインを取るたび時間が巻き戻る。敵はぜんぶ、過去のあなた。**

前のループで走った自分が「残像」になり、同じ道を往復しつづける。過去の自分をかわしながらループを重ねる、1画面のタイムループ・アクションです。

`index.html` 1ファイルで動きます。ビルドも依存もありません。ブラウザで開けばそのまま遊べます。

## モード

| モード | 内容 |
| --- | --- |
| エンドレス | 毎回ちがう配置でどこまでループを重ねられるか挑戦する |
| デイリー | 日付ごとにコインとアイテムの位置が固定。だれが遊んでも同じ配置なので、結果をコピーして友だちと比べられる |

## ルール

- コインを取るとループクリア。時間が巻き戻り、次のループが始まる。制限時間は8秒。
- 前のループの自分は **残像** になり、同じルートを往復しつづける。触れたらアウト。
- ループ開始直後の約1秒は残像に当たらない（点線表示）。

## ゲームの仕組み

| 仕組み | 効果 |
| --- | --- |
| 寄り道 | 寄り道したぶん残像の通り道が長くなり、後のループで自分の首を絞める |
| ダッシュ | 一瞬だけ加速し、残像をすり抜けられる（+15）。使ったあと約1.4秒は使えない |
| ニアミス | 残像に触れずにすぐ横をかすめると +25、一瞬スローモーション |
| CHAIN | 3秒以内のクリアが続くと、コインの得点倍率が最大×3まで上がる |
| 赤い消しゴム | 4ループごとに出現。いちばん長い残像を1体消せる（+50） |
| 砂時計 | 6ループごとに出現。残像の動きが2.5秒止まる（+30） |
| ECHO STORM | 10ループ目から5ループごと。残像が1.5倍速で動く |
| 予知ドット | 各残像の少し先の動きを点で表示（設定で切り替え可） |

コインの得点は「(100 + 残り秒数×10) × CHAIN倍率」です。

## やりこみ要素

- **実績 15種**：ループ数、ニアミス、CHAIN、ダッシュ封印などで解除。
- **スキン 6種**：実績を解除すると、プレイヤーの色が増える。
- **称号**：到達ループ数で「迷子」から「エコーマスター」まで。
- **記録**：モード別 TOP 5 と通算成績。
- **結果をコピー**：SNSに貼れる結果テキストをクリップボードへ。
- **軌跡を見る**：ゲームオーバー後、そのプレイで走った全ルートを1枚の絵として表示。

記録・実績・設定はブラウザの localStorage に保存されます（サーバーには送りません）。

## 操作

| | キーボード | タッチ / マウス | ゲームパッド |
| --- | --- | --- | --- |

## 設定

BGM と効果音の音量、画面の揺れ、フラッシュ演出、予知ドット、当たり判定の表示を変更できます。OS でアニメーションを減らす設定にしていると、揺れとフラッシュは最初からオフになります。

## 公開（GitHub Pages）

`.github/workflows/pages.yml` で、`main` ブランチへの push 時に GitHub Pages へ自動デプロイします。

1. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする。
2. このブランチを `main` にマージする（または Actions タブから手動実行）。
3. `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される。

## 技術メモ

- 素の HTML / CSS / JavaScript。Canvas 2D 描画、60 ステップ/秒の固定タイムステップ。
- BGM と効果音は Web Audio API でその場で合成（音声ファイルなし）。BGM はループ数に応じてテンポと楽器が増える。
- デイリーの配置は日付とループ番号から作るシード付き乱数で決まるため、プレイヤーの動きに関係なく同じ配置になる。
