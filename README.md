# エコーラン（ECHO RUN）

**コインを取ると時間が巻き戻る。さっきまでの自分は「残像」になって、同じ道を永遠に往復しつづける。**

過去の自分が敵になる、1画面のタイムループ・アクションです。`index.html` をブラウザで開くだけで遊べます（ビルド不要・依存なし）。

## ルール

- アリーナのどこかに出るコインを取ると、そのループはクリア。時間が巻き戻って次のループが始まる。
- 直前のループで走った軌跡は **残像** になり、以後ずっと同じルートを往復しつづける。
- **残像に触れたらゲームオーバー。** 敵はぜんぶ、過去のあなた。
- 各ループの制限時間は **8秒**。早く取るほどボーナスが増える。
- ループ開始直後の約1秒は残像に当たらない（点線表示）。

## 遊びのキモ

| 仕組み | 効果 |
| --- | --- |
| 寄り道 | 寄り道したぶん残像の通り道が長くなり、後のループで自分の首を絞める |
| ダッシュ | 一瞬だけ加速し、残像をすり抜けられる（すり抜け +15）。使うと約1.4秒のクールダウン |
| ニアミス | 残像のすぐ横をかすめると +25 とスローモーション |
| 赤い消しゴム | 4ループごとに出現。取ると **いちばん長い残像** を1つ消せる（+50）。ただし取りに行く寄り道も記録される |
| 予知ドット | 各残像の少し先の動きが点で表示される。過去の自分の動きは読めるはず |

スコア = コイン（100 + 残り秒数×10）+ ニアミス + すり抜け + 消しゴム。ベストスコアはブラウザに保存されます。

## 操作

| | キーボード | タッチ / マウス |
| --- | --- | --- |
| 移動 | WASD / 矢印キー | 画面をドラッグ（フローティングスティック） |
| ダッシュ | Space / Shift / J | DASH ボタン、または2本目の指でタップ |
| 一時停止 | P / Esc | 一時停止ボタン |
| リトライ | Space / Enter / R | もう一度ボタン |
